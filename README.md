# hardware_architecture

## Это репозиторий по дисциплине Архитектура аппаратных средств

Курс учит понимать, как устроен компьютер на аппаратном уровне и как взаимодействуют его ключевые компоненты. В целом он дает базу для того, чтобы разбираться в архитектуре вычислительных систем, принципах работы процессора и организации памяти, а также в основах представления данных (биты и байты) и логике взаимодействия устройств между собой.

### Здесь будет хранится:

- tests - папка с самостоятельными работами
