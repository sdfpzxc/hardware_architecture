# «Рабочий цикл процессора» 
---

## 1. Взаимодействие устройств ЭВМ в процессе выполнения машинной команды

**Основные понятия:**
- **Программа** — последовательность команд, направленная на преобразование входных данных в выходные (результат).
- Команды и данные текущей программы хранятся в **оперативной памяти (ОП)**.
- Выполняет команды **процессор**.

**Схема взаимодействия:**
- Процессор и ОП связаны тремя шинами:
  - **Шина данных** — передача данных.
  - **Шина адреса** — передача адресов.
  - **Шина управления** — управляющие сигналы (чтение, запись).

**Вопросы:** в каком виде хранятся данные и команды? Откуда процессор знает, где находится очередная команда и данные для неё?

---

## 2. Представление данных

Числа представляются в ЭВМ в **двоичной системе счисления** (форматы со знаком с фиксированной и с плавающей точкой).

**Пример:** `01101101` = 1·2⁰ + 0·2¹ + 1·2² + 1·2³ + 0·2⁴ + 1·2⁵ + 1·2⁶ = 1 + 4 + 8 + 32 + 64 = +109.

Старший бит — знаковый: 0 — положительное, 1 — отрицательное.

Символы представляются их двоичными кодами. Двоичные вектора (для поразрядных логических операций) — последовательностями битов (беззнаковые целые типы).

---

## 3. Представление команд

**Команда** — приказ компьютеру на выполнение какой-либо операции, например, сложения двух чисел (операндов), которые хранятся в оперативной памяти.

**Формат команды:**
- **Код операции (КОП)** — какая операция выполняется.
- **Адрес первого операнда** в ОП.
- **Адрес второго операнда** в ОП.

**Система команд процессора** — набор команд, который исполняет конкретный процессор. Включает:
- арифметические и логические команды;
- команды пересылки информации между регистрами и памятью;
- команды передачи управления;
- команды ввода-вывода и др.

**Пример:** фрагмент системы команд микроконтроллера KM1816BE51 (группа арифметических операций: ADD, ADDC, SUBB, INC, DEC, MUL, DIV и др.).

---

## 4. Аппаратное обеспечение (структурная схема)

**Регистры процессора:**
- **РК** — регистр команд (хранит текущую команду);
- **ПортА** — порт адреса;
- **ПортД** — порт данных;
- **Р1** — аккумулятор АЛУ (сюда загружается операнд, здесь же появляется результат);
- **Р2** — второй регистр АЛУ;
- **СчАК** — счётчик адреса команды (хранит адрес очередной команды).

**Регистры оперативной памяти (ОП):**
- **РАОП** — регистр адреса ОП;
- **РСОП** — регистр слова ОП.

**Другие устройства:**
- **АЛУ** — арифметико-логическое устройство;
- **УУиС** — устройство управления и синхронизации;
- **DC** — дешифратор КОП;
- **генератор синхросерии C**.

**Шины:** адреса (m линий), данных (n линий), управления.

**Чтение из ОП:** процессор выставляет адрес в РАОП, вырабатывает сигнал ЧтОП, данные появляются в РСОП и поступают по шине данных в порт данных.

**Запись в ОП:** процессор выставляет адрес в РАОП, данные в РСОП, вырабатывает сигнал ЗпОП.

## 5. Рабочий цикл процессора (на примере двухадресной арифметической команды)

### Этап 1. Выборка команды из ОП

1. **y₁: ПортА := СчАК** — процессор выставляет на шину адреса значение из счётчика команд.
2. **y₂: ЧтОП** — сигнал чтения из ОП.
3. **y₃: РК := ПортД** — команда с шины данных попадает в регистр команд.

### Этап 2. Выборка операндов из ОП

**2.1. Выборка первого операнда:**
4. **y₄: ПортА := A₁** — адрес первого операнда из РК на шину адреса.
5. **y₂: ЧтОП** — чтение из ОП.
6. **y₅: Р1 := ПортД** — первый операнд попадает в аккумулятор АЛУ.

**2.2. Выборка второго операнда:**
7. **y₆: ПортА := A₂** — адрес второго операнда из РК на шину адреса.
8. **y₂: ЧтОП** — чтение из ОП.
9. **y₇: Р2 := ПортД** — второй операнд попадает во второй регистр АЛУ.

### Этап 3. Выполнение операции в АЛУ

10. **КОП → DC → xᵢ → УУиС → yᵢ → АЛУ** — значение КОП расшифровывается на DC, формируется осведомительный сигнал xᵢ=1, УУиС выдаёт управляющий сигнал yᵢ^АЛУ=1, АЛУ выполняет операцию. Результат — в аккумуляторе Р1.

### Этап 4. Запись результата в ОП (на место первого операнда)

11. **y₈: ПортД := Р1** — результат из АЛУ на шину данных.
12. **y₄: ПортА := A₁** — адрес первого операнда на шину адреса.
13. **y₉: ЗпОП** — запись в ОП.

### Этап 5. Продвижение СчАК

14. **y₁₀: СчАК := СчАК + L** — счётчик команд увеличивается на длину выполненной команды (L байт).

**Упрощённая структурная схема процессора и ОП:**
- В процессоре должны быть выводы для сигналов Set (включить УУиС) и Reset (выключить).
- По включению УУиС вырабатывает сигнал y₀, устанавливающий СчАК на начальный адрес программы.

**Обобщённое УГО процессора:**
- Выводы: +5V, RESET, SET, CLC (можно подключить к внешнему генератору), GND.
- Порты: A (адреса), D (данных), RD (чтение), WR (запись), IN, OUT (для периферии).

**Микропрограмма работы процессора:**
```
y0, y1, y2, y3, y4, y2, y5, y6, y2, y7, y8, y4, y9, y10, ...
```
Далее — микропрограмма обработки прерываний (если возникли), затем — исполнение следующих команд.

**Условия работы:**
1. Система команд — 256 команд (КОП = 8 бит).
2. Два операнда в ОП (два поля адресов).
3. ОП — последовательность байтов, каждый байт имеет адрес.
4. Ширина шины данных — 32 бита.
5. Ширина шины адреса — 8 бит.
6. ОП хранит и данные, и команды (принстонская архитектура, фон Нейман).

## 6. Детализация работы АЛУ

**Вопросы:**
1. Как процессор узнаёт, что АЛУ закончило выполнение микропрограммы?
2. Где и как сохраняется признак результата?

**Решение:**
- АЛУ имеет выход **Z_АЛУ** (ШАЛУ(8) — сигнал «занято/свободно»).
- Пока АЛУ работает — Z_АЛУ = 1 (занято). Процессор ожидает.
- Когда Z_АЛУ = 0 (свободно) — результат в Р1, можно переходить к следующему этапу.

**Признаки результата (ШАЛУ):**
- ШАЛУ(0) = 1, если Р1 = 0;
- ШАЛУ(1) = 1, если Р1 < 0;
- ШАЛУ(2) = 1, если Р1 > 0;
- ШАЛУ(3) = 1, если переполнение с фиксированной точкой.

**Шифратор (Coder)** преобразует унитарный код в двухразрядный позиционный:
- 00 — результат равен нулю;
- 01 — результат меньше нуля;
- 10 — результат больше нуля;
- 11 — переполнение с фиксированной точкой.

**Флаги исключительных ситуаций (для плавающей точки и деления):**
- ШАЛУ(4) = 1 — переполнение порядка;
- ШАЛУ(5) = 1 — исчезновение порядка;
- ШАЛУ(6) = 1 — потеря значимости;
- ШАЛУ(8) = 1 — деление на ноль.

**Дополнительные регистры:**
- **РПР** — регистр признака результата (2 бита).
- **РФ** — регистр флагов прерываний ((s+1) разрядов).

**Сохранение результата:**
- y₈: ПортД := P1
- y₁₁: РПР(0:1) := Coder(ШАЛУ(0:3)) — только для add, sub, inc, dec, and, or, xor.
- y₁₂: РФ(0:4) := ШАЛУ(3:7) — флаги исключительных ситуаций.
- y₄: ПортА := A1
- y₉: ЗпОП

**Важно:** другие команды не должны изменять содержимое РПР!

## 7. Команды перехода

После арифметической (логической) команды СчАК всегда продвигается на длину команды. Для перехода к произвольной команде (разветвления, циклы) служат **команды перехода (передачи управления)**.

**Пример: команда условного перехода по маске.**

**Формат команды:**
- КОП — РК(0:7) (до 256 команд);
- М (маска) — РК(8:11);
- А (адрес перехода) — РК(12:n).

**Соответствие маски и РПР:**
| Разряд маски | Содержание РПР |
|---|---|
| РК(8) = 0 | = 0 |
| РК(9) = 1 | < 0 |
| РК(10) = 1 | > 0 |
| РК(11) = 1 | ППФТ (переполнение) |

**Правила:**
- Если M = 0 или A = 0 — переход не выполняется (нет операции).
- Если M = 1111 — безусловный переход.
- Если признак результата соответствует маске — СчАК замещается адресом A.
- Иначе — продолжается обычная последовательность.

**Разрядность адреса:** N_A = log₂(E_ОП).

**Схема вычисления сигнала x₄:**
- РПР(0), РПР(1) → DC → элементы И с РК(8)–РК(11) → элемент ИЛИ → x₄.
- Комбинационные схемы для x₁, x₂, x₃ разработать самостоятельно.

## 8. Прерывания

**Для поддержки прерываний в процессор введены:**
- **РФ** — регистр флагов прерываний;
- **УС** — регистр-указатель стека.

**Таблица векторов прерываний (ТВП):**
- В ОП первые n слов отведены под ТВП.
- Каждому биту Fᵢ в РФ соответствует причина прерывания и слово в ТВП.
- В i-ом слове ТВП — команда JMP Aᵢ на программу обработки прерывания.

**Обработка прерывания:**
1. ОП[УС] := СК; УС := УС + 1 (сохранение адреса возврата).
2. СК := i (адрес слова ТВП).
3. JMP Aᵢ — переход на программу обработки.
4. Выполнение программы обработки.
5. RETI: УС := УС − 1; СК := ОП[УС] (возврат).

**Типы прерываний:**
- **Исключения** — от АЛУ (деление на ноль, переполнение и т.п.), не маскируются.
- **Внешние** — от устройств (клавиатура, таймер), могут маскироваться.

**Мультипрограммный режим:** каждой программе выделяется квант времени (например, 1/30 с). По истечении — прерывание от таймера, переключение на другую программу.

**Аппаратная поддержка:**
- **РФ** — регистр флагов прерываний;
- **РМ** — регистр масок прерываний (i-ый бит = 1 — прерывание не обрабатывается).

**Недостаток:** сохраняется только адрес возврата. Программист сам должен сохранять/восстанавливать регистры.

**Слово состояния программы (ССП/PSW):** в некоторых системах сохраняются РПР, регистр масок и другие специальные регистры.

---

## Ключевые выводы

1. Рабочий цикл процессора: выборка команды → выборка операндов → выполнение → запись результата → продвижение СчАК.
2. АЛУ сигнализирует о завершении операции через Z_АЛУ; признаки результата сохраняются в РПР и РФ.
3. Команды перехода позволяют организовывать ветвления и циклы.
4. Прерывания обеспечивают реакцию на внешние события и исключительные ситуации; для возврата используется стек.
